Retail Sales Insights Using Clustering and PCA

K-Means, Gaussian Mixture and Hierarchical Clustering

Dataset: store_sales_dataset.csv

We group the orders into clusters using Quantity and Unit_Price with three unsupervised algorithms:

  1. K-Means
  2. Gaussian Mixture Model (mixture of Gaussians)
  3. Hierarchical (Agglomerative) Clustering

Category is not used for training. It is only used afterwards to check how well the clusters match the real categories.

4. Choosing the number of clusters (Elbow method + Silhouette score)

Show code
k_values = range(2, 9)
inertias = []
silhouettes = []

print(f"  {'k':>3} {'Inertia':>12} {'Silhouette':>12}")
for k in k_values:
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels = km.fit_predict(X_scaled)
    inertias.append(km.inertia_)
    silhouettes.append(silhouette_score(X_scaled, labels))
    print(f"  {k:>3} {km.inertia_:>12.2f} {silhouettes[-1]:>12.4f}")

best_k = list(k_values)[int(np.argmax(silhouettes))]

Retail Sales Insights Using Clustering and PCA

Principal Component Analysis (PCA)

Dataset: store_sales_dataset.csv

We reduce the dimensionality of the data with PCA:

  1. PCA from scratch (covariance matrix + eigen decomposition with NumPy)
  2. PCA with scikit-learn (to verify the manual result)

We then look at the explained variance, component loadings, reconstruction error and a 2D projection of the data.

Eigenvalues and explained variance

Show code
eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
# One-hot City columns always sum to 1, so one eigenvalue is ~0 (tiny negatives from rounding)
eigenvalues = np.clip(eigenvalues, 0, None)
order = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[order]
eigenvectors = eigenvectors[:, order]

explained_ratio = eigenvalues / eigenvalues.sum()
cumulative_ratio = np.cumsum(explained_ratio)

pc_names = [f"PC{i + 1}" for i in range(len(eigenvalues))]

print(f"  {'PC':<5} {'Eigenvalue':>12} {'Explained':>12} {'Cumulative':>12}")
for name, ev, ratio, cum in zip(pc_names, eigenvalues, explained_ratio, cumulative_ratio):
    print(f"  {name:<5} {ev:>12.4f} {ratio:>12.4f} {cum:>12.4f}")

n_components = int(np.searchsorted(cumulative_ratio, 0.90) + 1)
print(f"\nComponents needed to keep at least 90% variance: {n_components}")

X_pca_manual = X_scaled @ eigenvectors[:, :n_components]
